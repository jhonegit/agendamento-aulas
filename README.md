# Base das aulas, Agendamento Escolar

Este repositório guarda a **versão oficial** do projeto, sempre no ponto em que a
aula de hoje começa.

Toda aula começa aqui: baixar, extrair, abrir a pasta do dia. Quem faltou, quem
mudou de máquina ou apagou tudo começa no mesmo ponto que o resto da turma.

## Como pegar a pasta da aula

1. Aqui na página do GitHub, clicar no botão verde **Code**.
2. Clicar em **Download ZIP**. Não precisa estar logado em nada.
3. Na pasta Downloads, botão direito no arquivo, **Extrair tudo**. Sem extrair,
   nada funciona.
4. Abrir a pasta `agendamento-aulas-main`. Dentro dela tem uma pasta só, com o
   nome da aula de hoje (exemplo: `aula-04`).
5. No VS Code: **File → Open Folder**, e escolher essa pasta.

Trabalhar dentro dela mesmo. Não precisa copiar arquivo para lugar nenhum.

Aqui fica sempre uma aula só, a de hoje. Se a sua pasta tem outro número, você
baixou em outro dia: baixe de novo.

## Testando

Botão direito no `index.html`, **Open with Live Server**.
